Come ride

Like the mod? Join the server.

Ask for an invite, install the matching pack, and you're ready for your first lap. Availability depends on when the host is running the server.

Get an invite

Already know Griffdog21? Ask for the server address. Otherwise, use the GitHub invite request below to arrange connection details.

Install the pack

Use Fresh Tracks 1.3.0 for Minecraft Java 26.3 with Fabric. Import the .mrpack into Prism Launcher or Modrinth App. Installation guide →

Join and register

Open Multiplayer → Add Server and enter the address you receive. Once connected, type /register for your starter skis, snowboard and gear. No separate password.

Request an invite on GitHub →

GitHub requests are public. Share only your Minecraft username; arrange private contact details separately.

A few mountain rules

Be respectful, leave other players' gear alone, and enjoy the resort. Visitors can ski, ride lifts and shop. Placing or breaking blocks requires the owner's permission.

The Snowmass world is hosted on the server; it isn't included in the mod download.
